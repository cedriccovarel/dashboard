MYTOOLAPP - VERSION GITHUB PAGES

1. Dépose index.html dans ton dépôt GitHub.
2. Active GitHub Pages dans Settings > Pages.
3. Les applications ajoutées dans l'interface sont mémorisées dans le navigateur.
4. Les tuiles peuvent être déplacées avec la poignée ⋮⋮.
5. Le bouton Réglages permet de trier par nom ou de revenir à l'ordre personnalisé.
