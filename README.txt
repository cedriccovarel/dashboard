PRESTATERRE TOOLBOX - VERSION GITHUB PAGES
==========================================

Installation :
1. Cree un depot GitHub, par exemple "prestaterre-toolbox".
2. Depose le fichier index.html a la racine du depot.
3. Dans GitHub : Settings > Pages.
4. Source : Deploy from a branch.
5. Branche : main / root.
6. Le site sera disponible quelques instants plus tard sur GitHub Pages.

Fonctionnement de l'ajout d'applications :
- Clique sur "Ajouter une application".
- Choisis : Outil interne ou Site public.
- Renseigne le nom, le lien et éventuellement un logo.
- L'application est ajoutee immediatement au dashboard.

Important :
Cette version est 100 % statique et fonctionne sans serveur.
Les applications ajoutees via l'interface sont sauvegardees dans le navigateur (localStorage).
Elles ne modifient pas automatiquement le depot GitHub et ne sont donc pas partagees entre plusieurs ordinateurs.

Pour changer d'ordinateur :
- Ouvre Reglages.
- Clique "Exporter la configuration".
- Sur l'autre ordinateur, utilise "Importer une configuration".

Le dashboard contient deja des exemples :
- Generateur Prestaterre
- Rapprochement SIAP
- Google Sheets
- Google Drive
- ChatGPT
- Odoo
